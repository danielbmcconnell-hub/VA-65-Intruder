# Jungle and waterway reference originals

These are user-supplied reference images preserved byte-for-byte. `provenance.json` records original attachment groups, filenames, dimensions, file sizes and SHA256 hashes. All 20 images were copied exactly and independently decoded for validation. No image pixels, embedded metadata, watermarks or photographer credits were edited.

The directory labels follow the user's grouping. Exact animal identification, photograph authenticity, location and usage rights are not verified. Some images contain stock-provider watermarks or photographer credits; those remain in the originals. The jungle photographs are visual references and are not all independently established as Vietnam locations.

Gameplay integration is pending. This archival step does not add animals, hazards or scenery to the game. The existing runtime package allowlist excludes this reference directory. Earlier hands, weapons, radio and smoke photographs remain in their existing archives and were not mixed into these collections.
