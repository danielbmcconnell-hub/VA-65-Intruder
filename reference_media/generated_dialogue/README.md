# Original generic neural synthesis sources

These PCM16 WAV files are the original local Kokoro outputs, prior to runtime loudness normalization and MP3 encoding. No authentic/private voice recordings were used or altered. Exact source and runtime hashes, text, voice IDs and synthesis settings are in assets/audio/dialogue/manifest.json.

Generation used the public Apache-2.0 Kokoro v1.0 quantized ONNX model and MIT kokoro-onnx0.6.1. The executed generation script is preserved as generate.py; it records this workspace’s model/dependency paths and is not required to play the game. The model weights are not committed.
