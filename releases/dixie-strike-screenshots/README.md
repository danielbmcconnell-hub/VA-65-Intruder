# Dixie strike — actual browser captures

Linux Chromium/SwiftShader WebGL2; touch images are 844×390 DPR3 Chromium emulation, not physical iPhone Safari.

01–09 are native-input, fixed-step, genuine Standard sorties using the existing B/N pilot, ASQ-61, ballistics, damage and carrier wires. 09 is native reload/Continue from an actually earned checkpoint. 10–12 are explicitly placed camera/aircraft and isolated original-World blast fixtures, proving GPU geometry/ruins rather than another flown attack. The later ember-budget fix is covered by these final GPU fixtures and the packaged build; the earlier full-sortie hashes remain in its report.
