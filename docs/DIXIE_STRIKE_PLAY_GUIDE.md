# Dixie strike — work the B/N seat

In the Ready Room choose **BRIEF THE GUIDED STRIKE**, then **PLAY GUIDED SORTIE**. This opens the existing Mission 02 with the B/N station active. Your usual saved seat preference and the ordinary **Man Aircraft** option remain unchanged.

The pilot flies the existing aircraft and takes the catapult shot. You work navigation, target correlation, steering, designation and consent. The sortie ends successfully only when the original target objective is achieved and the crew recovers aboard the carrier. HOME requests a return; it does not award either objective.

1. **Navigate.** Study the target-area chart and public route landmarks. Open SCOPE, slew onto the actual checkpoint return and use the original LOCK. Watch system error and the next-fix indication. Desktop **X** remains an optional slew aid; it does not identify a target. **C / STEER** sends your cursor bearing to the existing pilot.
2. **Find the depot.** Open **B/N worksheet**. Compare the actual hard cluster with the public target area, three-way road junction, service row and water tower. Mark a chart candidate and use **LOOK OUT** to inspect that area from your aircraft before designating. Buildings outside the cleared area are scenery. The chart candidate and radar cursor are independent; **COMPARE ECHO** remains a working hypothesis. Daylight visual identification is still required by the briefing.
3. **Set up the run.** LOCK a return you judge appropriate. The pilot settles on the existing steering solution. Use **RIPPLE** to choose the original single/2/4/8 release quantity. A confirmed dispersed depot group can warrant eight bombs, keeping four for another run; single drops suit isolated points. You carry twelve Mk 82s; do not waste all of them on one uncertain point.
4. **Consent.** Hold **Space / COMMIT**. The original ASQ computer selects release; it refuses an invalid solution, excessive steering error or a second ripple before the run rearms. The crew explains why a held consent has not released. Release the control after the stick leaves.
5. **Assess.** **LOOK OUT** changes the view toward your current designation from your actual aircraft position. It does not move the aircraft or reveal an unseen target. Fire, fallen roofs, rubble, drifting smoke and delayed cook-offs come from real target destruction. A miss stays a miss. **BACK TO SCOPE** returns to the instruments.
6. **Choose.** **ANOTHER PASS** commands the original pilot to open range before returning. Reassess the remaining actual returns; firing repeatedly at empty ground wastes stores and exposes the crew. **HOME** turns the original pilot toward the ship, including after an unsuccessful attack.
7. **Recover.** Monitor fuel, damage, TACAN, gear and hook. The pilot must establish the stern approach before the existing landing system captures. You must catch a real arresting wire; merely reaching the ship cannot complete the sortie.

The first introduction offers **SHORT B/N PRACTICE**, an explicitly airborne start about 11 km from the target. It uses the same weapons, threats and objectives and still requires a real recovery. It is a shorter learning mode, not a different flight engine or an automatic success.

The guided sortie uses your existing difficulty setting. On the first attempt, use **Settings → Forgiving** if you need lower threat lethality. Standard threats remain dangerous, especially during repeated attack passes. If the pilot is incapacitated, the existing flight stick/keyboard controls become yours; EJECT, parachute descent and survival remain available.

**GUIDANCE** folds the detailed phase hints down. Crew subtitles are labelled dramatized gameplay dialogue; they are not quotations. Optional **SYNTH VOICE** uses a browser voice, defaults off and depends on device support. The ordinary engine, radio and effects controls remain in Settings.

Airborne checkpoints are earned on approach, during a stable run-in and during egress after pending bombs have settled. **RETRY**, the pause-menu retry or debrief retry creates a fresh Game with the recorded aircraft, damage, stores, target destruction, navigation and world placement. **CONTINUE CHECKPOINT** in the guided briefing resumes after closing the browser. Saves never import old callbacks or give credit for a bomb still in flight.

On iPhone use landscape orientation. Native controls have at least 44 px touch targets. Actual iPhone Safari performance, sound balance, backgrounding and rotation still need device testing.

Download the complete Dixie Strike Netlify ZIP, choose **Extract All** on Windows, then upload the extracted folder whose immediate children are `index.html`, `assets/` and `_headers` to the existing Netlify project's **Deploys** page. Keep the same origin to retain saves. The title identifies **Dixie Strike**. A file/Git delivery does not automatically redeploy the existing site.
