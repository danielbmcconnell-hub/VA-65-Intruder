# Tactical and visual update — playing the build

Deploy the complete `Intruder_Yankee_Station_Tactical_Visual.zip`, then reload the existing Netlify site. The page title ends **Tactical & Visual Update**. The website has not been updated merely by downloading this archive.

## Fly the B/N-led strike

1. Ready Room → **BRIEF THE GUIDED STRIKE** → **PLAY GUIDED SORTIE**. **SHORT B/N PRACTICE** starts airborne for faster learning; it carries the normal weapons and objectives.
2. **ROUTE** opens two optional approaches. **FLY DIRECT · 700 m** follows the published chart fixes. **FLY LOW DOGLEG · 320 m** adds surveyed terrain corners and requests lower clearance. Both use the existing pilot, whose terrain lookahead may climb higher. The low route offers different terrain exposure, not immunity from gunfire.
3. The folded route button displays distance to the next corner; open it for heading and the fix name. **MY STEERS**, the original **STEER/C**, or comma/period heading adjustments hand navigation back to you. Selecting a target hands control back to the original attack run. This aid does not perform radar fixes, identify the target or release weapons.
4. Use the worksheet's public chart and actual radar to find and designate the depot. **RIPPLE** cycles SINGLE / 2 / 4 / 8. A confirmed dispersed group can justify eight bombs, keeping four in reserve. Hold **COMMIT/Space** through the original computer release gates.
5. **LOOK OUT** observes the point you marked from the aircraft's actual position. Fire, smoke, secondary explosions and destroyed roofs follow real impacts. **ANOTHER PASS** opens range for a new run; **HOME** starts recovery. Neither command awards success: meet the original target objective and catch an actual carrier wire.
6. **RETRY** restores the last earned checkpoint, including damage, fuel, stores, destroyed targets and route/defense state. Pause and reload/Continue remain available.

The depot guns now need a clear view and time to acquire you. A ridge can break their tracking; they search their last sighting briefly and must reacquire. Other missions and the original small-arms system retain their previous rules. Instrument/crew cards report actual damage; directional impact cues use a known damaging weapon origin, with no invented enemy position.

## See the ground improvements

Ready Room's existing **POW chapters → Escape** entry opens the playable prison. Use the existing WASD/mouse or touch movement/look controls and contextual interactions. Observe guards moving through corridors and the yard. Later streets and riverbanks retain farmers, VC/NVA, hiding, sound investigation and collision.

Characters now use the intact supplied photographic sheet with stable perspective frames, distance-based cadence, eased starts/stops and feet anchored to the photographed foot line. These remain photographic cutouts with authored articulation; the sheet does not contain a complete filmed walk cycle. Their photographs, identities, collision and AI are preserved.

Medium/High graphics add restrained movement to at most 60 nearby photographic plants. Low graphics and distant vegetation retain the cheaper quad path. Richer depot meshes keep the existing draw budgets; crop detail fades before it becomes subpixel noise. Change quality in the existing settings if needed.

## Windows and iPhone deployment

Sign into the private GitHub repository and download the playable ZIP. On Windows choose **Extract All**. In the existing Netlify project, open **Deploys** and upload the extracted folder containing `index.html`, `assets/` and `_headers`. Keep this site's existing address to retain browser saves. For Git-connected Netlify use branch `tactical-visual-polish`, build `npm run build`, publish `dist/site`.

On iPhone use Safari in landscape. Test touch steering, COMMIT, route choices, pause/retry, rotation and audio after the initial tap. Automated mobile Chromium layout tests do not establish physical Safari compatibility or device frame rate.
