# Deploy Milestone 2.1

1. Sign into the private [VA-65-Intruder GitHub repository](https://github.com/danielbmcconnell-hub/VA-65-Intruder/tree/milestone2-1), select branch **milestone2-1**, and open [Intruder_Yankee_Station_Milestone2_1.zip](https://github.com/danielbmcconnell-hub/VA-65-Intruder/blob/milestone2-1/releases/Intruder_Yankee_Station_Milestone2_1.zip). Choose **Download raw file** to save the ZIP on your PC.
2. On Windows, choose **Extract All**. The extracted folder contains `index.html`, `assets/` and `_headers` at its root.
3. Upload this extracted folder through Netlify's manual deploy interface. Use a separate site or retain your previous deploy for comparison. Do not upload the source checkout, reference archives or evidence ZIP.
4. Open the HTTPS site in Windows Chrome and directly in iPhone Safari. Use landscape and Low/Medium graphics initially. Choose **Ready Room → Enter the prison** or **Continue POW checkpoint**, then follow the [play guide](MILESTONE_2_1_PLAY_GUIDE.md). Opening `index.html` in a file preview is not the hosted game.
5. For Git-connected Netlify, select branch **milestone2-1**, build command `npm run build`, and publish directory `dist/site`. The game is static; no backend, API key or secret is required.

The runtime allowlist includes the eight displayed historical photographs and preserved family tribute photographs. It excludes master/reference archives, source audit captures, Git history, development dependencies and tests. Site access should match your intended audience. This delivery does not change your live Netlify deployment.

Saved progress belongs to a browser on that exact origin; clearing storage removes it. Moving to another site does not automatically import prior saves. Existing Milestone 1 and Milestone 2 ZIPs, branches and tags remain available.

For your device trial, check all photographs, portrait/landscape wrapping, audio/available voices, pointer lock, left-stick/right-look input, F/Interact holds, Morse and wall-tap timings, imagined-space return/save, regular-camp patrols and doors, recapture, save/reload and app suspension. Emulated phone testing does not establish actual Safari or GPU performance.
