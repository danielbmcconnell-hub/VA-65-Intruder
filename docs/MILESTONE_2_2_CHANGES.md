# Milestone 2.2 changes

Based on the preserved Milestone 2.1 rooftop-rope hotfix, commit `975c9f22d612d11bbb376e318fbee0a36323b3b6`.

- Four direct playable chapter entries, a short action-based tutorial, separate chapter checkpoints and automatic migration of older campaign saves. Practice outcomes are labeled and do not complete flight missions.
- Two collision-backed subsequent escape approaches: a covered washing passage with cloth-muffled work, and a faster, louder workshop hinge. Normal patrols remain active through both routes.
- Actual visible/audible guard cues, reconstructed Vietnamese captions, directional and wall-muffled footsteps, smooth movement transitions and idle scanning. Calm movement in the permitted yard no longer incorrectly summons guards.
- Six river sections with bridge embankment, reed islands, ferry, floodplain, delta and Gulf context. Physical landings provide cover and rest. Careful swimming and crouched bank movement now produce less noise. New scenery avoids trapping actors restored from older saves.
- Earlier earned captivity pacing, with pauses for messages, changing guard duty, interviews, discoveries and transfer opportunities. Physical activity, counted communication, meals, rest and observation are still required.
- Aim-sensitive interaction targeting, a compact condition drawer, reticle and working hands using the existing first-person artwork. The bed's interaction point is reachable beside competing cell objects.
- Optional carrier and DIANE coaching reads existing instruments and records. Debrief advice describes measured flight behavior. A fixed-width hint panel prevents its touchscreen toggle moving between taps; it reports the existing gear-speed interlock accurately.
- Original renderer, full A-6A physics/model/markings, eleven mission definitions, rooftop-rope guidance and photographs preserved. Audio burst nodes disconnect on completion.

Actual browser testing covers rendering, controls, gameplay and upgrade compatibility. See the delivery test report for counts, fixtures and device limitations. No live Netlify deployment is included in the source commit; upload the runtime release through the existing project's Deploys page.
